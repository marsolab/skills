# CLAUDE.md

This file provides guidance to Claude Code (claude.ai/code)
when working with code in this repository.

## What This Repo Is

A dual-compatible plugin marketplace for Claude Code and
OpenAI Codex. Each plugin wraps one skill (a SKILL.md with
optional reference docs) and ships with platform-specific
manifests for both systems.

## Commands

```bash
# Regenerate all JSON manifests from SKILL.md frontmatter
uv run scripts/sync-manifests.py

# Check for manifest drift (CI uses this, exits 1 on diff)
uv run scripts/sync-manifests.py --check

# Lint Python
uvx ruff check scripts/
uvx ruff format --check scripts/

# Lint Markdown
mado check README.md CLAUDE.md
```

## Architecture

SKILL.md YAML frontmatter is the single source of truth
for all plugin metadata. Never edit `plugin.json` or
`marketplace.json` by hand -- they are generated by
`scripts/sync-manifests.py`.

The sync script reads every
`plugins/*/skills/*/SKILL.md`, extracts frontmatter
(name, description, version, tags), and writes:

- Per-plugin: `.claude-plugin/plugin.json` and
  `.codex-plugin/plugin.json`
- Root: `.claude-plugin/marketplace.json` and
  `.agents/plugins/marketplace.json`

Category and display-name mappings live as dicts inside
`scripts/sync-manifests.py` (`CATEGORIES`,
`DISPLAY_NAMES`). New plugins must be added there.

## Adding a Plugin

1. Create `plugins/<name>/skills/<skill-name>/SKILL.md`
   with frontmatter: name, description, version, tags
1. Add entries to `CATEGORIES` and `DISPLAY_NAMES` in
   `scripts/sync-manifests.py`
1. Run `uv run scripts/sync-manifests.py`
1. Commit all generated files alongside the SKILL.md

## CI / Releases

On push to `main`, the workflow
(`.github/workflows/release-skills.yml`):

1. Runs `uv run scripts/sync-manifests.py --check` to
   block merges with stale manifests
1. Detects which `plugins/` directories changed
1. Parses version from SKILL.md frontmatter
1. Creates a GitHub release with a `.skill` zip archive
   tagged `<plugin>-v<version>`

Versions containing `-`, `alpha`, `beta`, or `rc` are
marked as prereleases.

## Conventions

- Plugin directory names must match the SKILL.md
  `name` field (e.g., `plugins/go-dev/` for
  `name: go-dev`)
- Use kebab-case for all plugin and skill names
- SKILL.md files without a `version` field default
  to `1.0.0`
- On macOS, use POSIX-compatible shell syntax (no
  bash 4+ features) -- default macOS bash is 3.2
